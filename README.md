# ⚔️ ساحة القتال (Fight Arena)

لعبة قتال ثنائي 2D بين لاعبين حقيقيين، كل واحد من جهازه، بشخصيات مرسومة (بدون ملامح وجه إطلاقاً) ماسكة أسلحة متنوعة بيدها.

⚠️ تطبيق شخصي (side-load)، مش من متجر Google Play.

---

## ⚠️ خطوات إلزامية قبل أول بناء

### 1) أنشئ مشروع Firebase جديد
هالمرة **أبسط من FamilyMap** — بدون خرائط ولا تخزين صور، بس Authentication و Firestore.

1. 🔗 https://console.firebase.google.com → **Add project** → اسم مثلاً `FightArena`
2. أضف تطبيق أندرويد: **Android package name:** `com.ishhf.fightarena`
3. نزّل **google-services.json** وحطه جوا مجلد `app/`

### 2) فعّل تسجيل الدخول المجهول (Anonymous)
Firebase Console → **Authentication** → **Get started** → فعّل **Anonymous**

### 3) فعّل Firestore Database
Firebase Console → **Firestore Database** → **Create database** → **test mode**

روح لتبويب **Rules** والصق:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
واضغط **Publish**.

هيك بس! ما في خطوات تانية (ولا بطاقة، ولا خرائط، ولا تخزين).

## 🎮 طريقة اللعب

1. كل لاعب يسجل حساب (اسم + كلمة سر) بنفس التطبيق
2. بشاشة "ساحة القتال"، كل لاعب يختار سلاحه من القائمة (سيف / سكين / مسدس / بندقية / قوس — كل وحد ضرر ومدى وسرعة مختلفة)
3. **كل واحد لازم يضغط على اسم الطرف التاني من قائمة "اللاعبين المتاحين" تقريباً بنفس الوقت** عشان يلتقوا بنفس المعركة (هيك آلية "المطابقة" — تنسيق يدوي بسيط، مش مطابقة تلقائية معقدة)
4. أزرار ◀ ▶ للحركة، ⚔️ للهجوم (لو قريب كفاية من الخصم بمدى سلاحك، ينضرب تلقائياً)
5. 🎤 اضغط مطوّل للحكي (شرح الحدود تحت)
6. أول واحد صحته توصل صفر يخسر

## 🗣️ عن الميكروفون — الصراحة الكاملة

بما إنه ما في مكالمات حقيقية (WebRTC)، الميكروفون شغال بطريقة **"مقاطع متقطعة"**: كل ما تمسك الزر، بيسجل مقطع صوتي كل ٢ ثانية ويبعته فوراً للطرف التاني (مشفّر AES-256). **هاي مش مكالمة سلسة** — رح تحس فيها تقطيع وتأخير واضح بين كل مقطع والتاني، أشبه بجهاز لاسلكي (ووكي-توكي) مش مكالمة هاتف عادية.

---

## 🔐 التشفير

كل مقطع صوتي بيتشفّر بـ AES-256/GCM قبل ما يترفع لـ Firestore، وينفك بس وقت التشغيل بجهاز المستقبل.

## ⏱️ عن "بنفس اللحظة"

الحركة والهجوم بينزامنوا كل ١٥٠ ملي ثانية تقريباً (حسب سرعة نت الطرفين) — سلس وقابل للعب فعلياً، بس مش بسرعة استجابة ألعاب احترافية (PUBG وأمثالها بتستخدم سيرفرات ألعاب مخصصة بأجزاء من الميلي ثانية، وهاد خارج نطاق ما يقدر يقدمه تطبيق مبني على Firebase).

## 🪂 وضع الخريطة الكبيرة (١٠٠ شخصية)

زر جديد بشاشة اللوبي "🪂 الخريطة الكبيرة" — يفتح خريطة ٢D كبيرة (٤٠٠٠×٤٠٠٠ وحدة) بكاميرا بتتبعك، مع:

- **نزول بالمظلة** أول ما تدخل
- **٩٢ بوت محلي** يتمشوا عشوائياً بالخريطة — تقدر تضربهم وتكسب نقاط قتل. **مهم:** هاي البوتات محلية بجهازك بس، مش نفسها يلي شايفها لاعب حقيقي تاني بنفس اللحظة (تفصيل شرحناه قبل البناء)
- **دائرة زرقاء تتضيق** تدريجياً على مدى ١٠ دقايق — لو طلعت برا الدائرة، بتخسر صحة تدريجياً
- **لاعبين حقيقيين** يدخلوا نفس الخريطة بنفس الوقت بيتزامنوا فعلياً معك (حركتهم، صحتهم، ضرباتهم) — بس تحديث الموقع كل ٤٠٠ ملي ثانية (أبطأ شوي من المبارزة الثنائية) عشان نحافظ على حد الاستخدام المجاني مع عدد أكبر من اللاعبين المحتملين
- ميكروفون بتسجيل واحد لحد ١٥ ثانية (بدل مقاطع الثانيتين بالنسخة الأولى) — نفس مبدأ الدردشة بتطبيق العائلة، أوضح وأسهل استخدام

### ملاحظة تقنية أخيرة صادقة
تحديث اللاعبين الحقيقيين كل ٤٠٠ ملي ثانية (بدل ١٥٠ بالمبارزة الثنائية) معناه حركتهم على شاشتك ممكن تبين بقفزات بسيطة (مش سلسة ١٠٠٪) خصوصاً لو كتار لعبوا بنفس الوقت — هاد تنازل ضروري عشان اللعبة تضل مجانية وما توقف فجأة بسبب تجاوز حد Firebase.
